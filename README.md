# java-calculator-precourse

| **기능 ID** | **기능명** | **기능 설명** |
| --- | --- | --- |
| F01 | 사용자 입력 받기 | 콘솔에서 사용자가 덧셈할 문자열을 입력받는다. |
| F02 | 커스텀 구분자 탐색 | 입력 문자열이 `"//"` 로 시작하면 커스텀 구분자를 정규식으로 추출한다. |
| F03 | 커스텀 구분자 제거 | `matcher.end()` 로 `//X\n` 부분(0~4 인덱스)을 제거하여 순수 데이터 문자열만 남긴다. |
| F04 | 커스텀 구분자 유효성 검사 | 입력 문자열이 **숫자 + 기본 구분자(, :) + 커스텀 구분자**로만 구성되었는지 정규식으로 검사한다. |
| F05 | 커스텀 구분자 변환 | 커스텀 구분자와 기본 구분자(`:`)를 모두 `,` 로 통일한다. |
| F06 | 기본 구분자 유효성 검사 | 커스텀 구분자가 없는 경우, 문자열이 숫자 + 기본 구분자(`, :`)로만 이루어져 있는지 검사한다. |
| F07 | 기본 구분자 변환 | 커스텀 구분자가 없을 때, `:` 를 `,` 로 통일한다. |
| F08 | 숫자 분리 및 변환 | 통일된 문자열을 `,` 기준으로 분리하여 각 요소를 `int` 로 변환한다. |
| F09 | 합계 계산 | 분리된 정수들을 모두 더한 값을 계산한다. |
| F10 | 결과 출력 | 최종 합계를 콘솔에 출력한다. |
| F11 | 잘못된 입력 예외 처리 | 정규식 검증 실패 시 `IllegalArgumentException` 예외를 발생시켜 프로그램을 종료한다. |
| F12 | 프로그램 종료 | 예외 발생 시 프로그램을 즉시 종료한다. |


## 프로그램 처리 흐름
``````
[입력 받기]
↓
[커스텀 구분자 존재 확인]
↓
┌──────────────┬───────────────┐
│ 있음         │ 없음          │
│--------------│---------------│
│ (F02~F05)    │ (F06~F07)     │
└──────────────┴───────────────┘
↓
[정규식 유효성 검사]
↓
[숫자 분리 및 변환 (F08)]
↓
[합계 계산 (F09)]
↓
[결과 출력 (F10)]
↓
[예외 발생 시 (F11~F12) 프로그램 종료]

````
