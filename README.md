# java-calculator-precourse

| **기능 ID** | **기능명**          | **기능 설명**                                                                 |
| --------- | ---------------- | ------------------------------------------------------------------------- |
| **F01**   | 사용자 입력 받기        | 콘솔을 통해 덧셈할 문자열을 입력받는다. (`readLine()`)                                     |
| **F02**   | 입력값 비어 있음 처리     | 전체 입력이 비어있을 경우 결과값 `0`을 출력하고 프로그램을 종료한다.                                  |
| **F03**   | 커스텀 구분자 존재 여부 확인 | 입력이 `"//"` 로 시작하는 경우, 정규식(`^//(.)\\n`)을 통해 커스텀 구분자 존재 여부를 판단한다.           |
| **F04**   | 커스텀 구분자 추출       | 정규식을 이용해 커스텀 구분자 문자를 추출한다. (예: `//;\n1;2;3` → `;`)                        |
| **F05**   | 커스텀 구분자 제거       | 추출한 `Matcher`의 `end()` 위치 이후 문자열만 잘라서 순수 데이터 부분만 남긴다.                     |
| **F06**   | 커스텀 구분자 유효성 검사   | 입력 문자열이 **숫자 + 기본 구분자(, :) + 커스텀 구분자**로만 구성되어 있는지 정규식으로 검사한다.             |
| **F07**   | 기본 구분자 유효성 검사    | 커스텀 구분자가 없는 경우, 입력이 숫자와 기본 구분자(`,` 또는 `:`)로만 이루어져 있는지 검사한다.               |
| **F08**   | 구분자 통일           | 커스텀 구분자가 있는 경우 `:`와 커스텀 구분자를 모두 `,`로 변환한다. 커스텀 구분자가 없을 경우 `:`만 `,`로 변환한다. |
| **F09**   | 문자열 분리           | 통일된 문자열을 `,` 기준으로 분리하여 문자열 배열로 변환한다. (`split(",")`)                       |
| **F10**   | 빈 문자열 처리         | 분리된 요소 중 `""`(빈 문자열)인 경우 `0`으로 간주하여 합산 시 포함한다.                            |
| **F11**   | 합계 계산            | 모든 숫자 요소를 `int`로 변환하여 합계를 계산한다.                                           |
| **F12**   | 결과 출력            | 계산된 합계를 콘솔에 `"결과 : X"` 형식으로 출력한다.                                         |
| **F13**   | 잘못된 입력 예외 처리     | 정규식 검증에 실패하거나 잘못된 문자가 포함된 경우 `IllegalArgumentException`을 발생시켜 프로그램을 종료한다. |
| **F14**   | 프로그램 종료          | 예외 발생 또는 결과 출력 후 프로그램을 정상 종료한다.                                           |



## 프로그램 처리 흐름
```
[입력 받기 (F01)]
↓
[입력값 비어 있음 검사 (F02)]
 └── 비어있으면 → [결과 0 출력 후 종료]
↓
[커스텀 구분자 존재 확인 (F03)]
↓
┌──────────────────┬──────────────────┐
│ 있음             │ 없음             │
│------------------│------------------│
│ (F04~F06 처리)   │ (F07 처리)       │
└──────────────────┴──────────────────┘
↓
[정규식 유효성 검사 (F06/F07)]
 └── 실패 시 → [예외 발생 및 종료 (F13~F14)]
↓
[구분자 통일 (F08)]
↓
[문자열 분리 (F09)]
↓
[빈 문자열 0 처리 (F10)]
↓
[합계 계산 (F11)]
↓
[결과 출력 (F12)]
↓
[예외 발생 시 (F13~F14) 프로그램 종료]


```
